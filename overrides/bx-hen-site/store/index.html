PKG de teste da BX-HEN Store

O aplicativo nativo experimental já foi compilado com o OpenOrbis. Esta versão testa apenas a interface e a navegação pelo controle: não baixa nem instala PKGs.

Consultar builds do aplicativo de teste no GitHub Actions. Downloads de artefatos podem exigir uma conta GitHub e expiram após o prazo de retenção.

Como a lojinha funciona

O BX-HEN mantém apenas um catalog.json no site. Os PKGs poderão ficar em hospedagem externa, como Cloudflare R2, Backblaze B2 ou GitHub Releases, de acordo com a escolha do responsável pelos arquivos.

O botão de download só aparecerá quando houver URL HTTPS válida, versão, hash SHA-256 e licença de distribuição confirmada. A transferência abrirá um link externo: isso não significa instalação direta no PS4.

Seus projetos Java e Minecraft Online Manager estão cadastrados como em preparação, sem arquivos ou URLs inventados.
