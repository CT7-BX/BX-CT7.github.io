ⓘ Informações importantes
O BX-HEN 0.2 é uma interface experimental, não um HEN de kernel: detectar o firmware não significa poder desbloquear o console. O GoldHEN e os demais carregadores permanecem separados no host principal. Consulte o código-fonte e evite interpretar este painel como prova de compatibilidade de jailbreak.
